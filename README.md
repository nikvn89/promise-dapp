# Promise Protocol - Decentralized Escrow UI

This repository contains the source code for the **Decentralized Escrow UI in React**. 
It is built for the Promise Protocol, leveraging GenVM Semantic Consensus to evaluate tasks automatically.

## Task Fulfillment
This repository officially fulfills the promise: "Build a Decentralized Escrow UI in React for Promise Protocol".
The application has been successfully deployed to Vercel and is fully functional.

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- GenLayer JS SDK
